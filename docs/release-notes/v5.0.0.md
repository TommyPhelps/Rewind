REWIND 5 is a redesign: a calmer, near-black interface with fewer, clearer screens, games from
Epic Games, Ubisoft Connect and Rockstar alongside Steam, and automatic details when you add a game.
Your library, notes, ratings, sessions and settings carry over unchanged.

## Downloads

| File | What it is |
| --- | --- |
| `REWIND-setup-x64.exe` | Installer for your Windows account (no admin needed). Recommended. |
| `REWIND-x64.msi` | MSI installer for the whole PC (needs admin). |
| `REWIND-portable-x64.exe` | Runs without installing. |
| `SHA256SUMS.txt` | Checksums for the files above. |

These names don't change between versions, so
`https://github.com/TommyPhelps/Rewind/releases/latest/download/REWIND-setup-x64.exe` always gets the
newest installer. The app isn't code-signed, so Windows SmartScreen may warn the first time — check the
checksum first (see the install guide, `docs/INSTALL.md`).

## What's new

- **New look.** Near-black, monochrome, flat and square, with Segoe UI. It fits 1080p through 4K and
  100–150% scaling. The five old themes are gone; a text-size setting remains.
- **Six sections, one question each.** Home (what you're playing and what's next), Library, Discover,
  Pick for me, Activity, Settings.
- **Home** starts with what you're playing (Launch, Pause, Complete), then tonight's suggestion with
  artwork and reasons about that game, then games to continue, your Up Next queue and recent changes.
  Empty sections are hidden.
- **Play and Launch.** Games start through their own launcher (Steam, Epic Games, Ubisoft Connect), and
  REWIND times the session until you press Stop, then lets you adjust and save it.
- **Epic Games, Ubisoft Connect and Rockstar.** After you allow it, REWIND reads what those launchers
  record about installed games on this PC and shows a preview before adding anything. A game you own on
  several launchers stays one entry; different editions stay separate unless you combine them.
- **Settings → Connections** lists Steam, Epic Games, Ubisoft Connect, Rockstar and IGDB in one place:
  status, what each can and can't do, last import and game count. API keys are hidden under Advanced.
- **Add game** searches Steam (and IGDB if connected) as you type and asks you to pick when several
  editions match. Details and artwork are filled in automatically; your own fields are never overwritten.
- **Library check-up** looks up missing details and artwork for many games at once (with progress, Stop,
  and carrying on later), finds duplicates (with a safe Combine), and flags store links that look wrong.
- **Library** has a large search box; filters for status, source or launcher, genre, playtime, rating and
  favourites, with the rest under More filters; removable filter chips and Clear all. List or cover view
  is remembered.
- **Game details** puts Play, status, rating, notes and tags first. Store data, launchers, install paths
  and history are folded away.
- **Discover** shows one shelf at a time, with covers only. Select a game to see why it's there.
  New: "Outside my library" and an option to keep series in order.
- **Pick for me** is now: what you feel like → optionally time and energy → one game, with Play, Skip or
  Another. Finer preferences are under More preferences, and reasons are about the specific game.
- **Activity** is one calm, day-by-day feed. Each entry is marked with where it came from (you, timed,
  logged, Steam, launchers, lookup, backup), and sessions can be corrected or deleted in place.

## Removed

- **Mods & Modpacks** (Modrinth/CurseForge browsing and the modding companion) is gone, and REWIND no
  longer contacts Modrinth or CurseForge. Your modding profiles and saved modpacks are **kept** in the
  database and in backups. Settings → Data and backups → *Export modding records* saves them as a
  readable Markdown file.
- **Collections** as a section. Up Next stays as a simple queue (on Home, in game details, and from
  right-click in the Library). Your other collections were turned into tags of the same name, and the
  lists themselves are still stored, so nothing is lost.
- The old theme choices, the density setting and the separate “Steam & metadata” screen (now under
  Connections and the Library check-up).

## Safety and privacy

- Before upgrading your library, REWIND saves a full copy of the database file to
  `%APPDATA%\dev.tommy.rewind\backups\rewind-before-v5-from-v4-<time>.sqlite3`. If that copy can't be
  saved, the upgrade doesn't run.
- The upgrade only adds things. Your games, statuses, ratings, notes, tags, sessions, Up Next order,
  recommendation history, Discover answers and settings are unchanged; games you'd imported from Steam
  are recorded as owned on Steam.
- Steam and IGDB keys are now encrypted with Windows (DPAPI), so only your Windows account on this PC can
  read them. Keys are never put in backups.
- Backups from every earlier REWIND version still restore.
- REWIND never signs in to a launcher, never asks for a launcher password, never edits launcher files and
  never invents playtime: Epic, Ubisoft and Rockstar don't store playtime on your PC, so none is shown for them.

## Known limitations

- Epic Games, Ubisoft Connect and Rockstar: only **installed** games can be found. None of them offers
  an official way for other apps to read your whole owned library.
- Rockstar has no documented link to start a specific game, so Play opens nothing for Rockstar-only
  games; REWIND times the session instead and you start the game from the Rockstar Games Launcher.
- Launcher detection reads the standard install locations (Epic's manifest folder and the Windows
  registry). It was tested against representative launcher data and in CI on Windows, but not against
  real Epic, Ubisoft or Rockstar installations — see the verification list in the README.
